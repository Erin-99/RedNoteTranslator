# RedNote Translator

An Android accessibility service-based real-time translator for RedNote (XiaoHongShu) app. This application detects and translates Chinese content from the RedNote app in real-time and displays English translations in a floating window.

## Quick Start Guide

### Installation
1. Download the latest APK from [Releases](../../releases)
2. Allow installation from unknown sources in your Android settings
3. Install the APK

### First Time Setup
1. Open RedNote Translator app
2. Follow the on-screen instructions to:
   - Enable Accessibility Service
   - Allow overlay permission

### Usage
1. Open XiaoHongShu app
2. Browse any Chinese content
3. Translations will appear in a movable floating window
4. Drag the translation window to any position

## Features
🔄 Real-time translation of Chinese content in RedNote app
🪟 Floating window display for translations
💾 Local caching of translation results
🔋 Power-efficient design
🎛️ Customizable translation settings

## System Requirements
- Android 7.0 (API Level 24) or higher
- Requires accessibility service permission
- Requires overlay permission

## Troubleshooting
If translations don't appear:
1. Make sure both permissions are granted
2. Restart the RedNote Translator app
3. Check your internet connection
